# Index Platform v0.2.0

This release hardens the shared 1d3x, UGA Index, and SPIKE SPOT INDEX platform without changing calculation or publication rules.

## Highlights

- Current Next.js and Prisma patch lines with explicit Node 22 and npm 11 requirements.
- CI now checks repository health, dependency risk, lint, 356 tests, production environment contracts, and a full production build.
- Dependency advisories are reduced to the current WhatsApp/Puppeteer upstream backlog, which is review-dated and fails closed for new risks.
- A clearer public README, code/data licensing boundary, security policy, and contribution guide.
- Reviewable integration contracts for ABVX-OS, ID, agentsgen, SET, ABVX Agent Skills, and Git Tweet.

## Boundary

This source release does not itself publish an index, deploy a tenant, send a channel message, or prove that public values are current. Those operational checks remain separate.
