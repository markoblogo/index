# Index Platform v0.2.1

UGA now operates as a database-free, read-only presentation layer for compatible SPIKE SPOT INDEX public data.

## Changes

- Relays four shared SPIKE positions with their published values, dates, bases, changes, and respondent counts.
- Removes UGA's runtime dependency on PostgreSQL and reports SPIKE feed health instead.
- Makes the SPIKE source and lack of a separate UGA calculation explicit in the public product copy.
- Keeps UGA respondent, calculation, synchronization, and publication workflows inactive.
- Updates production environment validation and documentation for the read-through contract.

The SPIKE calculation and publication workflow is unchanged.
