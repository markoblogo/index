# Changelog

## [Unreleased]

## [0.2.1] - 2026-09-14

### Changed

- Replaced UGA's unavailable database runtime with a transparent read-only
  relay of four compatible SPIKE public positions.
- Updated UGA health, environment validation, product copy, and operational
  documentation for the database-free mode.

## [0.2.0] - 2026-09-14

### Added

- Public product navigation, ecosystem contracts, contribution guide, and security policy.
- agentsgen 0.5.1 context pack and SET 0.5.0 review-first `web-ui` plan.
- Auditable dependency-risk allowlist with expiry and fail-on-new-vulnerability behavior.
- Dependabot groups for production, development, and GitHub Actions updates.

### Changed

- Refreshed the supported Next.js and Prisma patch lines and declared Node/npm requirements.
- Hardened CI permissions, concurrency, timeouts, and action runtimes.
- Separated the MIT code grant from tenant data, methodology, brands, and content rights.
